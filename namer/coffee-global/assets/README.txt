Логотип проекта.

Положите загруженное изображение логотипа сюда под именем:
    logo.png

Интерфейс автоматически подхватит assets/logo.png в шапке (бренд-марк 46×46,
скруглённый, object-fit: cover). Пока файла нет — показывается запасная буква «N».

Поддерживаются png/jpg/svg — при другом расширении поменяйте src в src/ui.js
(logo.src = "assets/logo.png").
